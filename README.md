# InstiSword for Windows

Downloads of the **InstiSword** Windows installer, a calm, offline King James
Bible for reading and study, by DraeCo LLC.

**[Download the latest InstiSword-Setup.exe](https://github.com/thedee/instisword-releases/releases/latest/download/InstiSword-Setup.exe)**

- Windows 10 (1809) or later, 64-bit
- Installs for the current user; no administrator password needed
- More about the app: https://getdraeco.com/apps/instisword
- Support: https://getdraeco.com/apps/instisword/support

The installer is not yet code-signed, so Windows may show "Windows protected
your PC". Choose **More info**, then **Run anyway**.

This repository only hosts release downloads; the app's source code is not
published here.
